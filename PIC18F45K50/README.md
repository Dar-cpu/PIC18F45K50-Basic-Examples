# PIC18F45K50

Ejemplos básicos para el **PIC18F45K50-I/PT** de la tarjeta TECKIO.

Cada ejemplo se mantiene en su propia carpeta y contiene únicamente los archivos necesarios para entender y reutilizar la prueba.

## Índice

| Periférico | Ejemplo |
| --- | --- |
| GPIO | [all-gpio-test](gpio/all-gpio-test) |

Los siguientes ejemplos se incorporarán progresivamente después de ser compilados y verificados en hardware: ADC, Timer, PWM, UART, I²C, SPI y USB.

> Para programación por USB con el bootloader TECKIO, compila la aplicación desde `0x2000` usando el template/configuración correspondiente de MPLAB X.
